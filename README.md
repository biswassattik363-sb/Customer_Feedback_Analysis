 Customer Feedback Analysis

An Excel analytics project evaluating 5,000 customer feedback records to identify sentiment trends and department performance.

Executive Summary

Total Feedback: 5,000
Average Rating: 3.01 / 5.00
Satisfaction Breakdown: 40% Positive | 40% Negative | 20% Neutral

 Repository Contents

 Cleaned_Data: Cleaned dataset with sentiment labels (Positive, Neutral, Negative).
 Dashboard: Interactive Excel dashboard with KPIs, pie chart, and dynamic slicers.
 Analysis Overview: Key business insights and recommendations.

 Key Findings

Support Department: Lowest satisfaction rate with 42% negative ratings.
Sales Department: Highest satisfaction rate with 43% positive ratings.

  Recommendations

1. Retrain Support Staff: Focus on improving resolution speed and service quality.
2. Automate Escalations: Flag 1-star and 2-star feedback automatically to managers.

Tools & Technologies

Microsoft Excel: Data Cleaning, Pivot Tables, Interactive Slicers, and Visualizations.
